# 보관된 하네스

`slam_harness_humble/`은 기존 ROS 2 Humble·Gazebo Classic용 하네스입니다.
원본 소스를 보존하며 `COLCON_IGNORE`로 현재 Jazzy 워크스페이스의 빌드 대상에서 제외합니다.
폴더명 `archvie`는 요청하신 이름을 그대로 사용합니다.

현재 Jazzy 실행 방법은 [harness_ws 안내](../harness_ws/README.md)를 참고하세요.
보관 버전의 소스 실행 모듈 경로는 저장소 루트에서 `archvie.slam_harness_humble.main`입니다.
보관 폴더 내부 README/VALIDATION은 이전 실행 환경을 기록한 문서입니다.
